Adversarial multi-agent fact-checker. A Prosecutor and Defender argue opposite sides of a claim over retrieved evidence; every quote is checked against the source text by a deterministic verifier before a Judge rules — no LLM grades its own honesty. 96% quote grounding, 83% polarity accuracy on a 32-claim golden set. Ships as CLI, streaming web UI, and MCP server.

▸Hierarchical Reasoner

From-scratch PyTorch reproduction of Sapient's Hierarchical Reasoning Model (arXiv:2506.21734): a slow planner and a fast executor solving reasoning tasks in a single forward pass. 100% maze-path accuracy, a 66.7% compute reduction from ACT halting, 49 passing tests across 8 controlled experiments — plus an honest negative result on 9×9 Sudoku, root-caused and documented rather than hidden.

▸planrail

Powers aitrainingplan.app
Agentic pipeline for an AI training-plan app: a model proposes a plan, deterministic code validates it against real coaching constraints, and only what code genuinely can't fix is sent back to the model. Resolves every constraint violation at zero extra LLM calls on both test fixtures — repair before regenerate, not a model re-grading itself.

▸muscle-memory

An LLM works out how to complete a task inside a UI with no API; the successful run compiles into a typed, versioned capability that replays afterward deterministically, with no model in the loop. When it can't proceed safely, it hands the live session to a human and takes it back. Tested against a deliberately legacy mock banking app with injectable runtime faults.
PythonPlaywright

▸glassbox

Live demo
A GPT built from first principles in pure PyTorch, no HuggingFace. Attention, RMSNorm, RoPE, SwiGLU, grouped-query attention and a from-scratch BPE tokenizer, each tested before the next was added. A same-seed ablation improved validation loss with 12% fewer parameters. Ships with a live attention visualizer whose architecture diagram is generated from the model config, not hand-drawn.
PythonPyTorch

▸RepoSignal

A Chrome extension that scores any GitHub repo's trustworthiness before you add it as a dependency — maintenance, security, contributor risk, community, release hygiene and docs, weighted into a 0–100 verdict. No AI, no servers: every score computes locally from public GitHub data and is fully reproducible, with the weighting model itself tunable and exportable.
